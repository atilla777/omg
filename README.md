# OMG — Oh My Gas City

OMG — проект набора настроек и Agent Skills для разработки с помощью [Gas City](https://github.com/gastownhall/gascity). Цель — обсуждать требования с агентом, создавать по ним задачи и запускать их исполнение по формуле, не запоминая команды `gc`. Первый пользовательский клиент — OpenCode.

Сейчас работающих пакетов, формул, скиллов и slash-команд нет. [Общая идея](docs/project-vision.md), [согласованные сценарии](docs/workflow-requirements.md) и [архитектура скиллов](docs/skill-architecture.md) описывают планируемое поведение; правила разработки — в [AGENTS.md](AGENTS.md). Для будущих материалов предусмотрены `packs/`, `skills/`, `templates/`, `docs/` и `rules/`. План разработки ведётся отдельно в Obsidian: `B - работа Plums Lab/OMG/roadmap.md`.
