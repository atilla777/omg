# OMG — Oh My Gas City

OMG — проект набора настроек и Agent Skills для разработки с помощью [Gas City](https://github.com/gastownhall/gascity). Планируются переиспользуемые пакеты с формулами для типовых задач, а также инструкции для агента-оркестратора: проработка требований и планирование фич, выполнение запланированных задач и исправление ошибок.

Сейчас опубликована только основа проекта. Общая идея и границы описаны в [документе о проекте](docs/project-vision.md), правила его разработки — в [AGENTS.md](AGENTS.md). Для будущих материалов предусмотрены `packs/`, `skills/`, `templates/`, `docs/` и `rules/`. План разработки ведётся отдельно в Obsidian: `B - работа Plums Lab/OMG/roadmap.md`.
