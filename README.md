# OMG — Oh My Gas City

OMG — проект набора настроек и Agent Skills для разработки с помощью [Gas City](https://github.com/gastownhall/gascity). Цель — обсуждать требования с агентом, создавать по ним задачи и запускать их исполнение по формуле, не запоминая команды `gc`. Первый пользовательский клиент — OpenCode.

В [`packs/omg/`](packs/omg/pack.toml) находятся городской агент-оркестратор и скиллы для согласования, сохранения и поиска требований фичи в `docs/requirements/` выбранного rig, а также для отдельно подтверждённой декомпозиции в эпик и исходные подзадачи Beads. Сохранение требований не создаёт задач; декомпозиция не запускает их. Формул и запуска в pack пока нет. [Начальные контракты](docs/pack-contracts.md), [общая идея](docs/project-vision.md), [согласованные сценарии](docs/workflow-requirements.md) и [архитектура скиллов](docs/skill-architecture.md) описывают границы дальнейшей работы; правила разработки — в [AGENTS.md](AGENTS.md). План разработки ведётся отдельно в Obsidian: `B - работа Plums Lab/OMG/roadmap.md`.
