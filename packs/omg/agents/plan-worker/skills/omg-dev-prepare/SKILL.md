# Prepare the development workspace

Load `omg-dev-context` and follow its source/root and rig identity checks. This step creates the prepared workspace; later steps read it, never recreate it.

1. Claim the assigned step with `gc hook --claim --json`. Require `gc.step_id = omg-development.prepare`, the source's open state, and a requirements reference (if provided) resolving inside the rig. If ambiguous, leave the step open with a note explaining why.
2. Resolve the Git top-level of the selected rig, not the city. Require an accessible `origin/main`, a committed local `main` and a clean main worktree (`git status --porcelain`), without modifying rig Beads files. Fetch `origin/main` and check local `main`: if behind and clean, fast-forward it before preparing a dependent subtask; if diverged, stop for reconciliation. Verify the source ID is a safe single path component (`^[A-Za-z0-9][A-Za-z0-9._-]*$`). The branch is `task/<source-id>`; the per-rig root is `<rig-parent>/.omg-worktrees/<rig-directory-name>`, and the path is `<root>/<source-id>` (absolute, direct child). Create only the root directory when needed. Use Gas City's transactional owner, not raw `git worktree add`: `gc worktree ensure --repo <rig-path> --root <root> --path <path> --base main --branch task/<source-id> --bead <source-id> --store-ref rig:<rig-name> --creator omg-development --owner omg.plan-worker --generation <workflow-root-id> --json`. First use `--dry-run`, then run ensure and capture its JSON including provenance and `base_sha`. Verify the result with `gc worktree verify` using exactly the same arguments and the returned `--base-sha`. On incompatible provenance, stop; never reset or silently adopt an older worktree.
3. After `gc worktree verify`, inspect root metadata before writing: if any of `omg.workspace.path`, `omg.workspace.source_id`, `omg.workspace.artifacts_root` exists, require all three and require them to match the verified worktree, source ID and its `.omg/tasks/<source-id>/artifacts/` directory exactly; stop on mismatch, never replace an existing identity. Reject a symlink or path escaping the verified worktree at any component. Define this absolute artifacts directory once and create it only after these checks. Inspect `git -C <rig-path> ls-files .omg`: if any `.omg/tasks/` file is already tracked, stop for reconciliation; do not overwrite it. To ignore runtime artifacts in **this rig**, use an existing Git ignore rule, or append `/.omg/` to the repository's shared `git rev-parse --git-path info/exclude` only when `.omg/` has no tracked files; if it also contains tracked configuration append only `/.omg/tasks/`. Preserve existing entries, verify `git -C <worktree> check-ignore -q .omg/tasks/<source-id>/artifacts/context.md`. Do not stage this local workspace or change the rig's tracked `.gitignore` implicitly.
4. Write `context.md` under that directory with rig name, source ID/title/type, rig-relative requirements reference, root ID, base SHA, branch, worktree provisioning identity and artifact root. Record absolute worktree and context paths and branch in prepare notes (`--append-notes` when necessary), and `omg.workspace.path`, `omg.workspace.source_id`, `omg.workspace.artifacts_root` (absolute directory) on the root with `bd -C <rig-path> update` only if not already recorded. Read the file and metadata back; set `gc.outcome=pass` and close only prepare when they agree. On failure record what was created and leave the step open.
