# Review one attempt

Claim the assigned review bead; require positive `gc.attempt`, `gc.step_ref` ending in `review-loop.iteration.<attempt>.review`, and the root's `gc.var.source_id`. Read closed prepare/plan/implement/document beads for the same root and their recorded context and evidence. Inspect code, tests and documentation against the source criteria without editing. Use `bd -C <rig-path>` for all Beads operations.

For new roots read the absolute `omg.workspace.artifacts_root` from the workflow root; require `omg.workspace.source_id` and `omg.workspace.path` to match the source and verified worktree, and the directory to be `.omg/tasks/<source-id>/artifacts/` within it, without `..` or symlink escape. Create `review/attempt-<gc.attempt>/` inside that directory and write `review.json` and a separate human-readable `review.md` **in the same attempt directory**. Older roots without that metadata use `docs/tasks/<source-id>/review/attempt-<attempt>/review.json` in their prepared worktree without requiring a new Markdown report. Write JSON with `schema: omg.review.v1`, integer `attempt`, `source_id`, `workflow_root_id`, `review_step_id`, `verdict: approved|changes_required|blocked`, and `findings` (stable per-attempt IDs, severity, rig-relative affected files and actionable descriptions). For new roots include `markdown_report_path` (worktree-relative path of `review.md`) and `reviewed_files`: inventory `git -C <worktree> ls-files -m -o -d --exclude-standard -z`, record exactly these rig-relative paths with SHA-256 of each regular file (null for deletions), reject symlinks and unrelated changes. The map is a snapshot of **everything** reviewed for publication. The Markdown file explains the verdict and findings for this source/root/attempt without duplicating large prose in the bead. Approval has no findings; a blocker names its reason. Record the exact JSON path as bead `omg.review.report_path` and, for new roots, the Markdown path as `omg.review.markdown_path`. Read both files and metadata back, set `gc.outcome=pass` and close only this bead. If review or inputs are incomplete, leave it open with notes.
