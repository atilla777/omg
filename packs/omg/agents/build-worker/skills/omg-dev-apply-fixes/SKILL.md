# Apply review findings

Claim the routed `apply-fixes` bead in the selected rig. Read its `gc.root_bead_id`, `gc.attempt` and blocking `synthesize-review-scope-check` control (`gc.control_for` ends in `review-loop.iteration.<attempt>.synthesize-review`) through `bd -C <rig-path> dep list <step-id> --type blocks --json`. Follow the control's blocking dependency to the closed `synthesize-review` bead; require `gc.step_ref` ending in `review-loop.iteration.<attempt>.synthesize-review` and exact root/attempt equality. Runtime-spawned attempts may prepend the formula name to these references. Read **that synthesis bead's** `omg.review.synthesis_path`, validate its schema, `synthesis_step_id`, source ID, root ID and attempt against Beads. Do not search for the latest synthesis or use the initial `omg-dev-implement` instruction. Read the prepared worktree path from the prepare bead and verify its context before editing.

When `verdict=changes_required`, apply **only** the synthesis's mandatory fixes, preserving unrelated implementation, and run relevant tests from the same worktree. When `verdict=approved`, make no changes; verify that test evidence exists and record `status=no_op`. When `verdict=blocked`, do not edit or close successfully: return the blocker to the human. Write `docs/tasks/<source-id>/review/attempt-<attempt>/fix.json` with `schema: omg.review-fix.v1`, integer `attempt`, `source_id`, `workflow_root_id`, `synthesis_step_id`, `fix_step_id`, `status: applied|no_op`, `addressed_finding_ids` (array), changed files, `tests` (array of `{command, outcome: pass|fail}` with observed output), and remaining concerns. On an applied fix include at least one passing test and all `finding_ids` required by synthesis; an approved no-op has empty addressed IDs. Record its absolute path on this bead as `omg.review.fix_path`, read it back, set `gc.outcome=pass` and close only this bead after checks pass. On failed tests, leave it open with the evidence and reason. Never close initial implementation, source, or any prior attempt; never create another iteration yourself.
