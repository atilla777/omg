# Apply review fixes

Claim the assigned `apply-fixes` bead. Read its `gc.root_bead_id`, `gc.attempt`, and blocking `review-scope-check` control via `bd -C <rig-path> dep list <step-id> --type blocks --json`. Follow that control to the closed review bead of the same root/attempt, with `gc.step_ref` ending in `review-loop.iteration.<attempt>.review`; require the producer's `omg.review.report_path` and validate schema `omg.review.v2`, source/root/attempt and `review_step_id`. Do not search for the latest file. For already-started workflows whose blocker is `synthesize-review-scope-check`, continue to follow the closed synthesis bead and its `omg.review.synthesis_path` with schema `omg.review-synthesis.v1` as before. Verify the worktree recorded by prepare.

For `changes_required`, apply only `required_fixes` and run relevant tests; for `approved`, change nothing, verify test evidence and record `status=no_op`. On `blocked`, do not close and ask the human. For roots with `omg.workspace.artifacts_root` require that absolute path to match the source ID and verified worktree (`.omg/tasks/<source-id>/artifacts/`), without `..` or symlink escape. Require a positive `gc.attempt` matching the producer blocker and its recorded artifact in this attempt; write `review/attempt-<gc.attempt>/fix.json` there. Stop on missing or mismatched metadata, without searching by filename. Older roots without that metadata retain `docs/tasks/<source-id>/review/attempt-<attempt>/fix.json`. For direct review → fix write `schema: omg.review-fix.v2`, integer `attempt`, `source_id`, `workflow_root_id`, `review_step_id`, `review_report_path` (worktree-relative path to this review bead's report), `fix_step_id`, `status: applied|no_op`, `addressed_finding_ids`, rig-relative changed files, `tests` (`command`, `outcome: pass|fail`, observed output) and remaining concerns. For an existing synthesis workflow write the previous `omg.review-fix.v1` with `synthesis_step_id` instead of review links. Applied fixes require passing tests and all mandatory finding IDs. Record the exact path in this bead's `omg.review.fix_path`, read it back, set `gc.outcome=pass` and close only this bead after passing checks. Failed tests leave it open with a reason. Do not commit, close the source or create another iteration.
