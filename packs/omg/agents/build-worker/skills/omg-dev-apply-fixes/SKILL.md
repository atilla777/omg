# Apply review fixes

Load `omg-dev-context` and `omg-dev-review-attempt` and follow both shared contracts before reading or writing an attempt artifact. When asking the human or reporting a blocked step in Herdr, load `omg-human-dialog` and follow its question and result rules.

Claim the assigned `apply-fixes` bead. Require the direct review → fix workflow and the producing review artifact's `schema: omg.review.v2`; an already-started workflow with synthesis is not supported by the current checker, so leave its fix bead open and report that manual handling is required. For `changes_required`, apply only `required_fixes` and run relevant tests; if a fix writes durable documentation in `docs/`, load `omg-okf` before editing it. For `approved`, change nothing, verify test evidence and record `status=no_op`. On `blocked`, do not close and ask the human. Write `review/attempt-<gc.attempt>/fix.json` in the validated artifacts directory with `schema: omg.review-fix.v2`, integer `attempt`, `source_id`, `workflow_root_id`, `review_step_id`, `review_report_path` (worktree-relative path to this review bead's report), `fix_step_id`, `status: applied|no_op`, `addressed_finding_ids`, rig-relative changed files, `tests` (`command`, `outcome: pass|fail`, observed output) and remaining concerns. Applied fixes require passing tests and all mandatory finding IDs. Verify the report and its links, then record its exact path as `omg.review.fix_path` and its exact `status` as `omg.review.fix_status` on this bead; set `gc.outcome=pass`. **Before closing**, read back both beads and require exactly one closed passing review and one fix bead for this root and attempt with the matching step references. Require review metadata `omg.review.schema=omg.review.v2`, a report path pointing to the verified review artifact and `omg.review.verdict` matching it; require fix metadata `omg.review.fix_path` to point to this verified fix artifact, `omg.review.fix_status` to match it, and `gc.outcome=pass`. Only `approved/no_op` and `changes_required/applied` are valid pairs. On any missing, ambiguous or inconsistent metadata, record the reason and leave the fix bead open for repair: closing it would run the checker and spend an attempt on `gc 1.5.0`. The runtime check reads the recorded status, not the report contents. Failed tests leave it open with a reason. Do not commit, close the source or create another iteration.
