# Publish a reviewed subtask

1. Claim `omg-development.publish` in the selected rig. Read its `gc.root_bead_id`, root `gc.var.source_id`, and its closed `finalize` blocker; require matching root ID and `gc.outcome=pass`. Read `review-loop` from finalize's blocker and require `gc.outcome=pass` and an approved latest `synthesis.json` with no-op fix for that attempt. Read the exact `omg.publish.manifest_path` from root and the prepared worktree path `omg.workspace.path`; require source status open, type `omg-development`, and unchanged branch/worktree provenance. Verify manifest paths belong to this source's reviewed change; do not treat a completed review as permission to push any other source.
2. Resolve the helper from the root's `gc.formula_source`: the sibling `../assets/scripts/publish-development.py` in **this pack**. Verify it exists. Run `python3 <helper> publish --rig <rig-path> --worktree <worktree> --source <source-id> --root <root-id> --manifest <manifest-path>` as one operation. The helper takes a per-repository lock, checks the reviewed file hashes and base, refuses stale local/remote main or extra files, commits the task branch, pushes without force, then fast-forwards local main and writes `docs/tasks/<source-id>/publication-report.json` in the worktree. If remote main advanced, push was rejected, an unreviewed file changed or local main cannot be updated, **do not** bypass the helper or close the step; record the precise error and current local/remote/task SHA for deliberate reconciliation. A failed push after a local commit leaves a recognizable task commit, not a second workflow; retry only after reviewing the changed base.
3. Read the publication report and independently check `git ls-remote origin refs/heads/main`, `git -C <rig-path> rev-parse main`, and that the report's `remote_sha` and `local_main_sha` match each other and the observed main. Require the report's **task commit** to be an ancestor of that main (it can be behind a later valid publication). Record `omg.publish.commit=<task-sha>`, `omg.publish.report_path=<absolute path>` and `omg.publish.status=published` on both the publish step and root; read back the metadata. Set `gc.outcome=pass` and close only the publish step. Do not close the source here: the next bead independently verifies it. Do not delete the task worktree or artifacts.
